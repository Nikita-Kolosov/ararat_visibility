# Видно ли Арарат

PWA с прогнозом видимости Арарата из Еревана на сегодня, завтра и неделю.

Оценка строится по прогнозу [Open-Meteo](https://open-meteo.com/) (CC BY 4.0):
облачность над вершиной и по пути к ней, видимость и влажность в Ереване,
аэрозоли (дымка, пыль). Логика — в функции `score()` в `index.html`.

## Запуск локально

```bash
python -m http.server 8765
```

Открыть http://localhost:8765.

## Структура

- `index.html` — всё приложение (разметка, стили, логика)
- `manifest.webmanifest`, `icons/` — установка на телефон
- `sw.js` — офлайн-оболочка; последний прогноз хранится в `localStorage`

При изменении файлов оболочки увеличивайте `VERSION` в `sw.js`.
